## About This MicroSim

This interactive infographic separates clues visible on a component—bands, stripes, flat faces, printed values, notches, and dots—from ratings and pin functions that require a datasheet.

## How to Use

1. In **Explore** mode, click a column—or focus it with the keyboard and press Enter—to reveal a description and selection guidance.
2. Select **Quiz Me** and answer each use-case question by choosing the matching image.
3. Compare at least two columns and explain which visible and electrical differences matter most.

## Compared Items

1. Resistor color bands
2. Diode cathode stripe
3. Transistor flat face and part code
4. Capacitor value, voltage, and polarity marks
5. IC notch, dot, and part code

## Lesson Plan

### Grade Level

Grades 6–10; beginning electronics

### Duration

10–15 minutes

### Learning Objective

Students will identify what common markings reveal and explain when a datasheet is still required.

### Activities

1. **Explore:** Inspect each column and identify a visible clue.
2. **Compare:** Contrast two choices using the detail panel.
3. **Apply:** Complete the quiz and justify each selection aloud or in writing.

### Assessment

Give learners an unknown component and ask them to record visible facts separately from facts they must look up.

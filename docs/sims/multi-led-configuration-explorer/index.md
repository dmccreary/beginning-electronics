## About This MicroSim

This interactive infographic connects four visually distinct multi-LED arrangements to their wiring rules, control strategies, and ideal applications.

## How to Use

1. In **Explore** mode, click a column—or focus it with the keyboard and press Enter—to reveal a description and selection guidance.
2. Select **Quiz Me** and answer each use-case question by choosing the matching image.
3. Compare at least two columns and explain which visible and electrical differences matter most.

## Compared Items

1. Parallel LEDs with individual resistors
2. LED strip
3. LED matrix
4. LED chaser

## Lesson Plan

### Grade Level

Grades 6–10; beginning electronics

### Duration

10–15 minutes

### Learning Objective

Students will explain how current limiting, addressing, multiplexing, and sequencing differ across four multi-LED configurations.

### Activities

1. **Explore:** Inspect each column and identify a visible clue.
2. **Compare:** Contrast two choices using the detail panel.
3. **Apply:** Complete the quiz and justify each selection aloud or in writing.

### Assessment

Ask learners to select a configuration for indicators, an outline, a pixel display, and a moving-light effect.

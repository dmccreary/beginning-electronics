## About This MicroSim

This interactive infographic helps learners choose among four common project power sources by comparing voltage, current capability, portability, runtime, rechargeability, and safety.

## How to Use

1. In **Explore** mode, click a column—or focus it with the keyboard and press Enter—to reveal a description and selection guidance.
2. Select **Quiz Me** and answer each use-case question by choosing the matching image.
3. Compare at least two columns and explain which visible and electrical differences matter most.

## Compared Items

1. USB wall adapter
2. 9 V battery
3. Four-AA battery pack
4. LiPo pouch cell

## Lesson Plan

### Grade Level

Grades 6–10; beginning electronics

### Duration

10–15 minutes

### Learning Objective

Students will select a suitable source by balancing load current, voltage, portability, runtime, charging, and safety.

### Activities

1. **Explore:** Inspect each column and identify a visible clue.
2. **Compare:** Contrast two choices using the detail panel.
3. **Apply:** Complete the quiz and justify each selection aloud or in writing.

### Assessment

Present four project loads—a desk sensor, low-current alarm, small robot, and wearable—and require a justified source choice.

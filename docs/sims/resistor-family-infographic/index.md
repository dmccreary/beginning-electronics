## About This MicroSim

This interactive infographic compares fixed resistors, potentiometers, trim pots, photoresistors, and thermistors by what changes their resistance and where each is useful.

## How to Use

1. In **Explore** mode, click a column—or focus it with the keyboard and press Enter—to reveal a description and selection guidance.
2. Select **Quiz Me** and answer each use-case question by choosing the matching image.
3. Compare at least two columns and explain which visible and electrical differences matter most.

## Compared Items

2. Potentiometer

## Lesson Plan

### Grade Level

Grades 6–10; beginning electronics

### Duration

10–15 minutes

### Learning Objective

Students will distinguish fixed, human-adjusted, and environment-sensitive resistance and match each type to an application.

### Activities

1. **Explore:** Inspect each column and identify a visible clue.
2. **Compare:** Contrast two choices using the detail panel.
3. **Apply:** Complete the quiz and justify each selection aloud or in writing.

### Assessment

Select the best component for an LED limiter, volume knob, calibration adjustment, night detector, and temperature sensor.

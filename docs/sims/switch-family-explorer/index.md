## About This MicroSim

This interactive infographic compares the physical form and practical role of five common input components: tactile push buttons, toggle switches, slide switches, rocker switches, and DIP switches. It connects what each part looks like to whether it is momentary or latching, its typical contact arrangement, and the projects where it is most useful.

## How to Use

1. In **Explore** mode, click a switch column—or focus it with the keyboard and press Enter—to reveal its description, typical wiring, and recommended uses.
2. Select **Quiz Me** and answer each use-case question by choosing the matching switch image.
3. Compare the tactile push button's momentary behavior with the four latching switch styles.

## Lesson Plan

### Grade Level

Grades 6–10; beginning electronics

### Duration

10–15 minutes

### Learning Objective

Students will explain how the physical form, momentary or latching behavior, and typical wiring of five switch types make each suitable for different uses.

### Activities

1. **Explore:** Inspect every column and name one clue that distinguishes the switch.
2. **Compare:** Sort the five parts into momentary and latching groups.
3. **Apply:** Complete the use-case quiz, then justify each selection using behavior and form factor.

### Assessment

Ask learners to select a switch for a reset input, a main power control, and a bank of configuration settings, explaining why each choice fits.
